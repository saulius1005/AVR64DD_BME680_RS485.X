# Sensors Board for Weather Station v2.0

*(No image yet — work in progress)*

This board is part of a dual-axis solar tracking system and is used as part of the weather station. Its purpose is to:

1. Collect environmental data such as temperature, pressure, and humidity using the BME680 sensor.
2. Collect wind speed, wind direction, and light-level data.
3. Process all collected data and send it to the weather station for further solar-position correction calculations.

# AVR32DD20 — Work Explanation

## BME680

The BME680 sensor is connected via SPI. The SPI clock runs at 6 MHz (24 MHz / 4 = 6 MHz):

```text
CLK.h:
...
#define F_CPU 24000000UL // CPU speed
...
```

```text
SPI.c:
...
| SPI_PRESC_DIV4_gc;    // Clock prescaler
...
```

The BME680 is used only for measuring temperature, pressure, and humidity. The gas resistance parameter is not used because it is not considered a sufficiently useful or objective measurement for this application.

All functions were adapted from the original weather station `BME680.c` code, with significant modifications.

The final values are stored as:

```c
...
int32_t temperature;
int32_t pressure;
int32_t humidity;
...
```

in `BME680.h`.

## Wind and Light Data

Wind and light sensors provide analog signals. The wind sensor outputs a 0–5 V signal, which is reduced by a voltage divider on the PCB to a voltage suitable for the MCU.

All three parameters are measured using the MCU's 12-bit ADC with 16-sample accumulation. The MCU VDD is used as the ADC reference voltage.

Therefore, the MCU must first measure its own supply voltage. This value is then used to calculate the wind speed, wind direction, and light level:

```c
ADC.c:

...
    if (channel != MCU_ch)
        ADC0_sensors[channel]->result = (uint16_t)(((uint32_t)answer * ADC0_sensors[MCU_ch]->result / 4096));
    else
        ADC0_sensors[channel]->result = (uint16_t)((uint32_t)answer * 1024 / 409.6);
    ADC0.COMMAND = ADC_SPCONV_bm; // Stop conversion
...
```

All parameters except the MCU supply voltage are then sent to Weather Station v2.0.

## RS485 Data Frame

Because this is currently only a prototype and there is only one device on this RS485 line, no device ID is used.

However, each data frame still ends with a CRC-8/CDMA2000 checksum.

The data frame starts and ends with `[` and `]`.

Example:

**`[1a03eb3b120004e322]`**

The data is structured as follows:

* **`1a`** — temperature in °C (26 °C), sent as a `uint8_t` value. The weather station will later convert it to an `int8_t`.
* **`03eb`** — pressure in hPa (1003 hPa), sent as a `uint16_t` value.
* **`3b`** — humidity in % (59%), sent as a `uint8_t` value.
* **`12`** — wind speed in m/s (18 m/s), sent as a `uint8_t` value.
* **`00`** — wind direction value from 0 to 7:

  * `0` — N
  * `1` — NE
  * `2` — E
  * ...
  * `7` — NW
* **`04e3`** — voltage generated by the SFH206K photodiode, used as the current light-level value (1251 mV). In the future, this sensor will be replaced with a sensor more suitable for visible-light detection, such as the BPW21 or SFH2716AC1.
* **`22`** — CRC-8/CDMA2000 checksum.

In total, the complete data frame contains **9 bytes of data**.

For now, the data is transmitted at **230400 baud**:

```c
USART.c:

...
USART0.BAUD = (uint16_t)USART0_BAUD_RATE(230400);
...
```
